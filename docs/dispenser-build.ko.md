# 디스펜서 제작 설명서 — 회로 + 골판지 조립

SG90 서보 4개와 골판지로 슬롯 마켓의 실물 배출 장치를 만드는 설명서.
전자공학 경험 없이 따라할 수 있게 썼고, 공식 하나(§5.2)만 계산하면
어떤 크기의 상품에도 맞출 수 있다.

완성되면: 손님이 슬롯의 정확한 금액을 보냄 → 워처가 감지 → ESP32가
해당 슬롯의 서보를 돌림 → 골판지 푸셔가 맨 아래 상품을 밀어 떨어뜨림.

## 1. 부품과 공구

| 부품 | 수량 | 대략 가격 | 비고 |
|---|---|---|---|
| ESP32 dev board (WROOM-32 등) | 1 | ¥15 | WiFi 되는 아무 변형 |
| SG90 서보 | 4 | ¥5/개 | 이미 1개 있으면 3개만 |
| 5V 2A 전원 어댑터 + DC잭 브레이크아웃 | 1 | ¥10 | **일반(멍청한) 어댑터** — 스마트 충전기는 저전류에서 출력을 끊는다 (실제로 겪음) |
| 점퍼선 (수-수, 수-암) | 20가닥 | ¥5 | |
| 브레드보드 (선택) | 1 | ¥5 | 전원 분배용; 없으면 전선 직결+납땜/테이프 |
| 골판지 | 택배박스 2~3개 | ₩0 | 이중 골판지(두꺼운 것)가 좋다 |
| 아이스크림 막대 or 나무젓가락 | 4개 | ₩0 | 푸셔 암 보강 |

공구: 글루건(필수), 커터칼, 철자, 연필, 박스테이프.

## 2. 회로

```
                  ┌──────────────┐
   USB 전원 ────►│    ESP32     │
                  │              │        SG90 (슬롯 1~4)
                  │  GPIO 18 ────┼──────► 슬롯1 신호 (주황/노랑)
                  │  GPIO 19 ────┼──────► 슬롯2 신호
                  │  GPIO 21 ────┼──────► 슬롯3 신호
                  │  GPIO 22 ────┼──────► 슬롯4 신호
                  │  GND ────────┼──┐
                  └──────────────┘  │
                                    │  ★ 공통 그라운드 — 이 선이 빠지면
   5V 2A 어댑터 ──┬─────────────────┼──── 서보가 미친 듯이 떨린다
                  │ 5V ──► 서보 4개의 V+ (빨강) 전부
                  └─ GND ─► 서보 4개의 GND (갈색) 전부 + ESP32 GND
```

규칙 세 개:
1. **서보 전원은 ESP32의 5V 핀에서 뽑지 않는다.** SG90 하나가 순간적으로
   0.7A를 먹는데 ESP32 보드의 레귤레이터는 그걸 못 버티고 브라운아웃된다.
   반드시 별도 5V 어댑터에서.
2. **GND는 반드시 공통.** 어댑터 GND ↔ 서보 GND ↔ ESP32 GND가 전부
   이어져야 신호가 성립한다. 서보가 지멋대로 떨리면 십중팔구 이거다.
3. 신호선(주황)만 ESP32 GPIO로 간다. 핀 번호를 바꾸고 싶으면
   `onchain_vending.ino`의 `SLOT_SERVO_PINS[]`를 같이 바꾼다.

## 3. 펌웨어 플래시

1. Arduino IDE 설치 → 보드 매니저에서 **esp32** 설치 → 라이브러리
   매니저에서 **ESP32Servo** (Kevin Harrington) 설치.
2. `firmware/onchain_vending/onchain_vending.ino` 열고 상단 세 줄 수정:
   `WIFI_SSID`, `WIFI_PASSWORD`, `WATCHER_BASE_URL`(부스 노트북의 LAN IP,
   예: `http://192.168.0.42:8787` — 노트북에서 `ipconfig getifaddr en0`).
3. 업로드 → 시리얼 모니터(115200)에서 `Connected, IP: ...` 확인.

## 4. 골판지 구조 — 설계 원리

방식: **중력 매거진 + 서보 푸셔.** 상품을 세로 통(매거진)에 쌓고, 맨
아래 상품만 서보 암이 수평으로 밀어 앞으로 떨어뜨린다. 위 상품들은
중력으로 한 칸 내려온다. 트랩도어 방식보다 재고를 여러 개 적재할 수
있어서 슬롯 마켓에 맞다.

```
   옆에서 본 단면 (슬롯 1개)

   │        │  ← 매거진 (상품이 세로로 쌓임)
   │ ┌────┐ │
   │ │상품3│ │
   │ ├────┤ │
   │ │상품2│ │
   │ ├────┤ │
   │ │상품1│ │ ← 맨 아래 칸 (배출구 높이 = 상품 두께 + 5mm)
   └─┤    ├─┴───────
     └────┘  ──►  푸셔 암이 밀면 앞으로 낙하
  ═══╧════╧═══════════  ← 바닥판
   [SG90]△              ← 서보는 매거진 뒤에, 암이 배출구를 쓸고 지나감
```

제약 (SG90 토크 1.8kg·cm의 물리학):
- 상품은 **가볍고(100g 미만) 단단한 포장**이어야 한다 — 스티커 팩, 뱃지,
  엽서, 납작한 사탕갑 OK. 말랑한 봉지·무거운 것 NG.
- 상품끼리 미끄러져야 한다 — 매거진 내벽에 박스테이프를 붙이면 마찰이
  확 준다 (걸림 방지의 핵심).

## 5. 재단과 조립

> 📐 **치수가 들어간 도면: [`docs/drawings/dispenser-v1.svg`](drawings/dispenser-v1.svg)**
> — 재단 시트, 측면 단면, 푸셔 궤적, 4슬롯 배치까지 4장. 브라우저로 열고
> 인쇄해서 옆에 두고 작업하면 된다. 도면은
> [`docs/drawings/generate.mjs`](drawings/generate.mjs)가 상품 치수 3개에서
> **생성**하는 것이라, 다른 상품을 팔 거면 그 파일 맨 위 `P`만 고치고
> `node docs/drawings/generate.mjs`를 다시 돌리면 전체가 따라 바뀐다.

### 5.1 예시 기준 상품

아래 치수는 **60×60×10mm 스티커 팩 + 이중골판지 5mm** 기준. 다른 상품이면
§5.2 공식(또는 도면 재생성)으로 다시 계산.

재단 목록:

| 조각 | 크기 | 수량 |
|---|---|---|
| 매거진 옆판 | 75 × 120mm | 8 (슬롯당 2) |
| 매거진 뒷판 | 65 × 120mm | 4 (하단 중앙에 **암 통과 슬릿 30 × 12mm**) |
| 매거진 앞판 | 65 × **105**mm | 4 (120이 아님 — 짧은 15mm가 배출구) |
| 푸셔 암 | 15 × 65mm, 골판지 2겹 + 아이스크림 막대 | 4 |
| 바닥판 (공용) | 350 × 105mm | 1 (서보 구멍 23 × 13mm ×4) |

옆판이 75mm인 이유: 내부 깊이 65 + 앞판 5 + 뒷판 5. **골판지 두께를 빼먹으면
조립 후 내부가 좁아져서 상품이 안 들어간다** — 이게 제일 흔한 실수다.

### 5.2 치수 공식 (아무 상품에나)

상품이 가로 W × 세로 D × 두께 T, 골판지 두께 t (mm)일 때:

- 매거진 내부 단면: **(W+5) × (D+5)** — 여유 5mm, 더 크면 안에서 기울어져 걸린다
- 옆판 폭: **(D+5) + 2t** · 앞뒤판 폭: **W+5**
- 배출구 높이 (앞판 하단을 띄우는 만큼): **T + 5** — 두 개가 같이 나오면 이 값을 줄인다
- 매거진 높이: **T × 재고 수 + 40**
- **푸셔 암 길이 (서보 축 → 암 끝): ≥ D/2 + 15 + 2t**, 여유 10mm 더할 것
  — 60×60×10 상품에 t=5면 최소 55, 도면은 65를 쓴다. 이 공식이 보장하는 건
  "상품 무게중심이 바닥판 앞 모서리를 넘어간다"는 것이고, 넘어가야 떨어진다
- 바닥판 깊이: **서보 20 + 10 + 매거진 깊이** — 바닥판은 앞판과 **같은 선에서
  끝난다.** 더 튀어나오면 밀려나온 상품이 안 떨어지고 그 위에 얹혀 있는다
- 바닥판 폭 (n슬롯): **(매거진 폭 + 10) × (n−1) + 매거진 폭 + 20**

### 5.2b 서보 높이 — 도면에서 제일 중요한 한 가지

SG90을 바닥판 **위에 눕혀 붙이면 축이 20mm 높이에 온다.** 상품 두께가 10mm면
암이 상품 위를 스쳐 지나가고 아무것도 안 밀린다.

그래서 바닥판에 **23 × 13mm 구멍**을 뚫고 서보를 **아래에서 위로 끼운다.**
SG90의 양쪽 귀(플랜지)가 바닥판에 걸려서 그대로 고정되고, 축은 바닥면에서
약 5mm 위 — 정확히 10mm 두께 상품의 중심 높이다. 브래킷도 나사도 필요 없다.

### 5.3 조립 순서

1. **매거진 접착**: 옆판 2 + 뒷판을 ㄷ자로 글루건 접착. 앞판은 **아래를
   배출구 높이만큼 띄우고** 접착. 내부에 박스테이프를 세로로 붙여 매끈하게.
2. **바닥판에 세우기**: 매거진을 바닥판 위에 수직으로 접착. 배출구가
   바닥판 앞쪽 모서리에서 **상품 세로 길이만큼** 떨어지게 — 밀린 상품이
   모서리를 넘어 떨어져야 하니까.
3. **푸셔 암 만들기**: 골판지 2겹 사이에 아이스크림 막대를 넣고 접착
   (골판지 단독은 몇 번 밀면 꺾인다). 한쪽 끝을 서보 혼(흰 십자)에
   글루건 또는 작은 나사로 고정.
4. **서보 장착**: 바닥판의 23 × 13mm 구멍에 **아래에서 위로** 끼운다
   (§5.2b). 플랜지가 걸리면 그대로 고정 — 글루건은 흔들림 방지용으로
   귀 주변에만 살짝. 몸통 전체를 바닥판 위에 붙이면 축이 너무 높아져서
   암이 상품 위를 헛돌게 된다.
   ⚠ 접착 전에 §6의 각도 확인 먼저 — 휴지 상태(0°)에서 암이 매거진
   **뒤쪽으로** 비켜나 있어야 상품이 걸림 없이 내려온다. 도면 패널 3의
   REST 위치 참고.
5. **4슬롯 배치**: 바닥판 위에 매거진 4개를 나란히. 왼쪽부터 슬롯
   1→4 = GPIO 18→22 순서로 배선을 맞춘다 (키오스크 슬롯 번호와 일치해야
   운영자가 헷갈리지 않는다).
6. 낙하 지점 앞에 공용 수거함(골판지 상자 하나)을 붙이면 완성.

## 6. 슬롯별 시험과 캘리브레이션

조립 중 결제 없이 서보를 돌리는 방법 — **부스 노트북에서** (localhost
전용, 다른 기기에선 403):

```bash
curl -X POST localhost:8787/slot-dispenses/test \
  -H 'content-type: application/json' -d '{"slotId":1}'
```

3초 안에(보드 폴 주기) 슬롯 1 서보가 한 사이클 돈다. 재고·판매·정산은
전혀 건드리지 않는다.

조정 순서:
1. 상품 없이 슬롯마다 test → 암이 배출구를 완전히 쓸고 제자리로
   돌아오는지 확인.
2. 상품 1개 넣고 test → 안 밀리면: 암 길이를 늘리거나
   `SERVO_DISPENSE_DEG`(기본 90)를 키운다. 두 개가 밀리면: 배출구
   높이를 줄인다(앞판 아래에 골판지 조각 덧대기).
3. 상품 가득 채우고 test 3연속 → 걸림 없이 연속 배출되면 통과.
4. 서보마다 편차가 있다 — 혼(십자 날개)을 스플라인에서 빼서 한 칸
   돌려 끼우면 15°씩 오프셋 조정이 된다. 펌웨어 상수는 전 슬롯 공용이니
   기계적으로 맞추는 게 먼저다.

## 7. 트러블슈팅

| 증상 | 원인 → 처치 |
|---|---|
| 서보가 지직거리며 떨림 | 공통 GND 누락(§2 규칙 2) 또는 전원 부족(어댑터 확인) |
| test는 도는데 상품이 안 밀림 | 암이 상품 옆면 중심을 안 지나감 → 서보 높이 재조정; 또는 암 길이 부족(공식 D+20) |
| 상품 두 개가 같이 나옴 | 배출구가 너무 높음 → T+5로 줄이기 |
| 상품이 중간에 걸려 안 내려옴 | 매거진 내벽 마찰 → 박스테이프; 단면 여유가 5mm보다 작음 |
| 몇 번 쓰니 암이 휘었다 | 골판지 단독 암 → 아이스크림 막대 보강(§5.3-3) |
| 보드가 폴은 하는데 안 돔 | 시리얼 모니터에서 `slotId out of range` 확인 — `SLOT_SERVO_PINS[]` 개수와 워처 `SLOT_COUNT` 불일치 |
| test가 403 | localhost가 아님 — 부스 노트북 터미널에서 실행 |

## 8. 연결 확인 (엔드투엔드)

1. 워처 실행 → 키오스크 슬롯 탭에서 슬롯 1 임대 (고유 가격, 재고 수량 입력)
2. 실물 재고를 매거진에 적재
3. https://faucet.circle.com 에서 그 슬롯의 **정확한 금액**을 부스 지갑으로 전송
4. 수십 초 안에: 워처 로그 `[slots] sold ...` → 서보 작동 → 상품 낙하 →
   키오스크에 판매 1 · 임차인 수익 표시 (핫키 있으면 지급 tx 링크까지)

여기까지 되면 "기계 하나, 사업자 여러 명"이 골판지와 서보 네 개로 실물이
된 것이다.
